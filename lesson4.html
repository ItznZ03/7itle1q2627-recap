Core Concepts

Computer Number Systems

System Description
Binary (Base 2) Uses digits 0 and 1. It is the core language of computers representing ON/OFF states of electronic switches.
Octal (Base 8) Uses digits 0 through 7. Used as a compact notation for grouping binary numbers in digital electronics and in UNIX systems.
Decimal (Base 10) Uses digits 0 through 9. The standard positional numbering system used by humans.
Hexadecimal (Base 16) Uses digits 0–9 and letters A–F (A=10, B=11, C=12, D=13, E=14, F=15). Commonly used in memory addressing.
Step-by-Step Methods

Number Conversions

1. Decimal to Base n (Division Method)

Used to convert a standard base-10 number into Binary (Base 2), Octal (Base 8), or Hexadecimal (Base 16).

  1. Divide the decimal number by the target base n.
  2. Record the remainder: the first remainder is the Least Significant Bit (LSB).
  3. Repeat division with the quotient until it reaches 0. The last remainder is the Most Significant Bit (MSB).
  4. Read from MSB to LSB (bottom to top).
Example (Decimal 13 to Binary Base 2):
13 ÷ 2 = 6 (rem 1) ← LSB
6 ÷ 2 = 3 (rem 0)
3 ÷ 2 = 1 (rem 1)
1 ÷ 2 = 0 (rem 1) ← MSB
Result (MSB → LSB): 1101₂

2. Base n to Decimal (Positional Expansion)

Used to convert Binary, Octal, or Hexadecimal back into a standard Base-10 Decimal number.

  1. Identify positional values: start with power n⁰ at the LSB (rightmost bit) up to nk at the MSB (leftmost bit).
  2. Multiply each digit by its corresponding power of n.
  3. Sum all values together to get the final Decimal value.
Example (Binary 1011₂ to Decimal):
Position 3 (MSB) to Position 0 (LSB):
(1 × 2³) + (0 × 2²) + (1 × 2¹) + (1 × 2⁰)
= 8 + 0 + 2 + 1 = 11₁₀

3. Binary to Hexadecimal (4-Bit Grouping)

Direct shortcut conversion without needing full decimal intermediate calculations.

  1. Group the binary digits into sets of 4 bits starting from the LSB (right side) moving towards the MSB (left side).
  2. Pad the MSB group with leading zeros if it contains fewer than 4 bits.
  3. Convert each 4-bit block into its Hexadecimal value (0–9, or A–F for 10–15).
Example (Binary 11010110₂ to Hex):
MSB group | LSB group: 1101 | 0110
1101 = 13 (Hex D)
0110 = 6 (Hex 6)
Result: D6₁₆
